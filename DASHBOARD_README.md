# XAUUSD Trading Bot - Real-Time Web Dashboard

A professional real-time web dashboard for monitoring your AI trading bot with live metrics, charts, and performance analytics.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Start the Dashboard
```bash
python run_dashboard.py
```

Or with custom options:
```bash
python run_dashboard.py --port 8000          # Custom port
python run_dashboard.py --host 0.0.0.0 --port 5000  # Custom host and port
python run_dashboard.py --debug              # Debug mode (for development)
```

### 3. Access the Dashboard
Open your browser and go to:
```
http://localhost:5000
```

## 📊 Features

### Real-Time Metrics
- **Balance & Equity**: Current account balance and trading equity
- **P&L**: Today's profit/loss with percentage return
- **Open Positions**: Number of active trades with limit indicator
- **Win Rate**: Percentage of winning trades
- **Max Drawdown**: Maximum peak-to-trough decline
- **Profit Factor**: Ratio of gross profit to gross loss

### Live Charts
- **Equity Curve**: Account value over time (line chart)
- **Trade Distribution**: P&L distribution by trade (histogram)
- **Win/Loss Ratio**: Visual breakdown of winning vs losing trades (doughnut chart)
- **Daily Performance**: Daily P&L by date (bar chart)

### Trading Data Tables
- **Open Positions**: Current open trades with entry price, P&L, stops
- **Recent Signals**: Latest model predictions with confidence scores
- **Trade History**: Complete trade history with entry/exit details

### Dashboard Components
- **Bot Status**: Indicator showing if bot is online or offline
- **Auto-Refresh**: Automatic updates every 3 seconds
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Dark Theme**: Easy on the eyes for 24/7 monitoring
- **Debug Logs**: View recent bot logs for troubleshooting

## 🎨 User Interface

### Layout
The dashboard is divided into sections:

1. **Top Navigation** - Bot status, last update time
2. **Key Metrics** - 6 main metric cards in responsive grid
3. **Performance Charts** - 4 charts showing trading performance
4. **Open Positions** - Table of current open trades
5. **Trading Signals** - Cards showing latest predictions
6. **Trade History** - Paginated table of recent trades
7. **Debug Logs** - Collapsible section with recent log lines

### Color Coding
- **Green** (#4ade80): Profits, winning trades
- **Red** (#ef4444): Losses, losing trades
- **Blue** (#3b82f6): Neutral, open trades
- **Orange** (#f59e0b): Warnings, risk levels

### Responsive Breakpoints
- **Desktop**: 1200px+ (full 4-column grid)
- **Tablet**: 768px-1199px (2-column grid)
- **Mobile**: <768px (single column, stacked)

## 🔧 Configuration

### Dashboard Settings
Edit `dashboard/data_parser.py` to customize:

```python
# Refresh interval (milliseconds)
DASHBOARD_CONFIG['refresh_interval'] = 3000  # 3 seconds

# Cache TTL (seconds)
self._cache_ttl = 10

# Log file path
TradingDataParser(log_file='logs/trading.log')

# Max records to display
limit=50  # Default max trades displayed
```

### Running on Different Port
```bash
python run_dashboard.py --port 8080
```

### Running on Specific Host
```bash
python run_dashboard.py --host 192.168.1.100 --port 5000
```

## 📊 Data Sources

The dashboard reads data from:

1. **Trading Logs** (`logs/trading.log`)
   - Trade events (opened, closed)
   - Signals generated by AI model
   - Balance updates
   - Error messages

2. **Configuration** (`config/config.py`)
   - Initial balance
   - Risk parameters
   - Position sizing rules

3. **Demo Data** (fallback)
   - If log file not found, generates demo trades for UI testing

## 🔄 Auto-Refresh Behavior

- **Refresh Interval**: 3 seconds (configurable)
- **What Updates**: All metrics, tables, charts
- **What Doesn't**: Log tail (only on manual refresh or startup)
- **Page Hidden**: Updates pause when tab is not visible
- **On Focus**: Updates resume when tab becomes visible again

## 🚨 Troubleshooting

### Dashboard Won't Start
```
Error: ModuleNotFoundError: No module named 'flask'
```
**Solution**: Install dependencies
```bash
pip install flask flask-cors
```

### No Data Displayed
1. Check if bot is running
2. Check log file exists: `logs/trading.log`
3. Check bot status indicator in dashboard
4. Verify log file is being written to
5. Check browser console for errors (F12)

### Charts Not Rendering
1. Check Chart.js is loaded (browser console)
2. Try refreshing page (F5)
3. Check browser supports Canvas
4. Try different browser
5. Enable JavaScript if disabled

### Metrics Not Updating
1. Check auto-refresh is enabled
2. Check API endpoints respond: `http://localhost:5000/api/metrics`
3. Check network tab in browser dev tools (F12)
4. Try manual page refresh
5. Check Flask app is running (no errors in terminal)

### Only Demo Data Shown
This is normal if bot hasn't traded yet:
- Dashboard starts with synthetic data
- Once bot starts trading, real data appears
- Check "Trade History" table for actual trades
- Watch equity curve grow as bot trades

## 📈 Performance Optimization

### For Large Datasets
- Limit trades displayed: Change `limit=50` parameter
- Reduce refresh interval: Increases CPU load
- Use pagination for trade history

### Browser Performance
- Close unused tabs
- Disable console logging in production
- Use modern browser (Chrome/Firefox/Safari)
- Clear browser cache if slow

### Server Performance
- Use production WSGI server (gunicorn, waitress)
- Run on dedicated port
- Monitor CPU and memory usage

## 🔐 Security

### Local Network Only
By default, dashboard only allows local connections:
- `0.0.0.0:5000` (accessible from any interface)
- `127.0.0.1:5000` (localhost only)

### For Production Deployment
```bash
# Run behind nginx/apache reverse proxy
# Use strong authentication
# Run with gunicorn (not debug mode)
gunicorn -w 4 -b 0.0.0.0:5000 "dashboard.app:create_app()"
```

### No Authentication Yet
Dashboard currently has no login. To secure:
1. Use a reverse proxy with authentication
2. Run on trusted network only
3. Use firewall to restrict access

### Customizing the UI

#### Change Colors
Edit `static/css/style.css`:
```css
:root {
    --accent-profit: #4ade80;    /* Green for profits */
    --accent-loss: #ef4444;      /* Red for losses */
    --primary-bg: #1a1a1a;       /* Dark background */
}
```

#### Add New Metric Card
Edit `templates/index.html`:
```html
<div class="metric-card">
    <div class="metric-header">
        <span class="metric-label">New Metric</span>
        <span class="metric-icon">📊</span>
    </div>
    <div class="metric-value" id="my-metric">0.00</div>
</div>
```

Then update in `static/js/dashboard.js`:
```javascript
function updateMetrics() {
    // ... existing code
    updateElement('my-metric', data.my_metric);
}
```

#### Add New API Endpoint
Edit `dashboard/app.py`:
```python
@app.route('/api/my-endpoint', methods=['GET'])
def my_endpoint():
    # Your logic here
    return jsonify({"data": "..."}), 200
```

### Adding More Charts
1. Add canvas element to `templates/index.html`
2. Create chart function in `static/js/charts.js`
3. Call from `initializeCharts()` in `static/js/dashboard.js`
